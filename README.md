# ssr-plus-install

SSR Plus+ 一键安装脚本（mipsel_24kc / OpenWrt 24.10）。

```sh
wget -qO- https://cdn.jsdelivr.net/gh/d5f6y7/ssr-plus-install/install.sh | sh
```

ipk 来自 [d5f6y7/openwrt-ssr-plus-build](https://github.com/d5f6y7/openwrt-ssr-plus-build) 的 release（tag `mipsel_24kc-openwrt-24.10`），为 OpenWrt 24.10 / mipsel_24kc 新编译的最新版 SSR Plus+。
